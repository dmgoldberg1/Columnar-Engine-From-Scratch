# Columnar Engine From Scratch

Учебный колоночный движок, реализованный с нуля на C++, демонстрирующий основные принципы работы современных аналитических СУБД (OLAP). Проект включает собственный колоночный формат хранения данных, движок исполнения запросов, алгоритмы сжатия и базовые оптимизации, используемые в промышленных системах.

## Возможности

- Собственный бинарный колоночный формат хранения данных
- Батчевая обработка данных
- Исполнение запросов по pull-модели
- Чтение только необходимых колонок (projection pushdown)
- Пропуск батчей по статистикам min/max (block skipping)
- Поддержка фильтрации (`WHERE`)
- Агрегатные функции:
  - `COUNT`
  - `SUM`
  - `AVG`
  - `MIN`
  - `MAX`
  - `COUNT DISTINCT`
- `GROUP BY`
- `ORDER BY`
- Оптимизация `ORDER BY ... LIMIT`
- Поддержка типов:
  - `Int16`
  - `Int32`
  - `Int64`
  - `Double`
  - `String`
  - `Date`
  - `Timestamp`

## Сжатие данных

Для различных типов данных реализованы специализированные алгоритмы кодирования и сжатия:

- Bit Packing
- Delta Encoding
- Dictionary Encoding
- Delta-Length Byte Array Encoding
- Адаптивный выбор алгоритма для строковых колонок

## Архитектура

Движок состоит из нескольких основных компонентов:

- собственный колоночный формат хранения;
- хранение метаданных и статистик батчей;
- Scan, Filter, Aggregation, Group By и Order By операторы;
- батчевая модель исполнения запросов;
- механизм пропуска нерелевантных батчей;
- библиотека для чтения и записи данных.

## Производительность

Проект протестирован на бенчмарке **ClickBench** и сравнивался с DuckDB.

Основные результаты:

- выполнение типичных аналитических запросов;
- ускорение до **3.8×** на селективных запросах благодаря block skipping;
- сравнение различных алгоритмов сжатия строковых колонок.
