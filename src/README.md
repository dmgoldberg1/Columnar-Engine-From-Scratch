# src

Короткое описание модулей внутри `src`.

## column_types
Здесь лежит базовая абстракция `Column` и конкретные физические типы колонок:
- `Int16`, `Int32`, `Int64`
- `String`
- `Double`
- `Date`
- `Timestamp`

В этом модуле сосредоточена логика:
- хранения значений колонки в памяти
- сравнения и фильтрации строк
- вычисления `min` / `max` / `count distinct`-вспомогательных операций
- сериализации и десериализации колонок
- сжатия и распаковки данных

## csv_wrapper
Обёртка над чтением CSV.

Этот модуль отвечает за:
- построчное чтение входного CSV
- разбор строки на токены с учётом кавычек
- подготовку `Scheme` по переданным типам и именам колонок


## file_writer
Запись данных в собственный колоннарный бинарный формат.

Модуль отвечает за:
- сбор строк из CSV в `row group`
- преобразование строкового представления в typed columns
- кодирование и сжатие каждой колонки
- запись batch-данных в файл
- запись metadata, схемы и block stats (`min` / `max` по батчам)

## file_reader
Чтение собственного колоннарного бинарного формата.

Модуль отвечает за:
- чтение metadata и схемы из файла
- восстановление границ батчей
- чтение нужных колонок из конкретного batch
- десериализацию колонок через `SetData()`
- доступ к block stats для block skipping

## operators
Исполнительный слой движка.

Здесь находятся операторы запроса:
- `ScanOperator`
- `FilterOperator`
- `GlobalAggregationOperator`
- `GroupByAggregationOperator`
- `OrderByOperator`
- `OrderByLimitKOperator`

А также:
- фильтры (`CompareFilter`, `LikeFilter`, `AndFilter`, `OrFilter`, `NotFilter`)
- аккумуляторы агрегатных функций (`SUM`, `AVG`, `COUNT`, `MIN`, `MAX`, `CountDistinct`)

Это основной модуль, где собирается pipeline выполнения запросов.

## scheme
Небольшой модуль для описания схемы таблицы.

`Scheme` хранит:
- имена колонок
- типы колонок
- отображение имени колонки в её индекс
- сериализацию и десериализацию схемы

Используется и writer'ом, и reader'ом, и операторами.

## utilities
Общие утилиты, которые переиспользуются в остальных модулях.

Сюда сейчас входят:
- enum `Types`
- парсинг и форматирование `Date` / `Timestamp`
- hash-функции для `int64`, `double`, `string`
- `HashCombine`
- вспомогательные данные вроде `GetHitsColumnNames()`
